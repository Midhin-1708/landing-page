# Responsive Landing Page

A modern and responsive landing page built using **React (Vite)** and **Tailwind CSS** as part of my frontend training assignment.

## Features

- Responsive Sticky Navbar
- Mobile Hamburger Menu
- Hero Section with Gradient Background
- About Section
- Services Section
- Features Section
- Contact Form with Validation
- Success and Error Messages
- Footer with Quick Links and Contact Information
- Scroll-to-Top Button
- Active Navigation Highlight

## Technologies Used

- React.js
- Vite
- Tailwind CSS
- JavaScript (ES6+)
- React Router

## React Concepts Used

- Functional Components
- Props
- useState
- useEffect
- Event Handling
- Form Validation
- Conditional Rendering
- Rendering Lists using `map()`
- Component Reusability

## Tailwind CSS Concepts Used

- Flexbox
- Grid
- Responsive Breakpoints
- Gradient Backgrounds
- Hover Effects
- Shadows
- Rounded Corners
- Transitions

## Validation

The contact form validates:

- All fields are required.
- Valid email format.
- Valid 10-digit phone number.
- Displays success and error messages.
- Alerts automatically disappear after 10 seconds.

## Bonus Features

- Scroll-to-Top Button
- Active Navigation Highlight
- Form reset
